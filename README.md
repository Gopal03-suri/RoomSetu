# 🏠 RoomSetu - Smart Roommate Matching Platform

Find your perfect room & roommate with AI-powered compatibility matching.

## 🚀 Quick Start

```bash
# Start both servers
start_app.bat
```

Then open:
- **Frontend**: http://localhost:5173
- **Backend**: http://localhost:8000
- **Admin Panel**: http://localhost:8000/admin
